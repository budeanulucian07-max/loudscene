# Security

If you find a security issue in the CLI, the MCP bridge or the loudscene API, please email
**contact@loudscene.com** with "security" in the subject instead of opening a public issue. Include
the steps to reproduce and what an attacker could do. We reply as soon as we can and credit
you in the changelog once it is fixed, if you want.

Never paste an API key (`ls_live_…`) into an issue. If one leaked, revoke it at once in
loudscene → Settings → API keys and create a new one.
